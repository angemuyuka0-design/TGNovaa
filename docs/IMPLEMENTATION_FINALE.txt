🛠 ARCHITECTURE TECHNIQUE

Structure JavaScript:
  discussions-firebase.js
    ├─ initialiserDiscussionsFirebase() - Démarrage système
    ├─ chargerConversations() - Écoute conversations temps réel
    ├─ chargerConversation(id) - Sélectionne conversation
    ├─ chargerMessagesEnTempsReel(id) - Écoute messages
    ├─ envoyerMessage(texte) - Envoie message + maj conversation
    ├─ gererIndicateurSaisie() - Ajoute utilisateur à "entrain d'écrire"
    ├─ arreterIndicateurSaisie() - Retire utilisateur après 3s
    ├─ ecouterIndicateurSaisie(id) - Écoute les typers
    ├─ creerNouvelleDiscussion() - MISE À JOUR: support type + description
    ├─ reconstruireListeConversations() - Rerender liste côté client
    └─ [Utilitaires: formatHeure(), echapperHTML(), afficherToast()]

  discussions-modal-advanced.js
    └─ afficherModalNouvelleDiscussion()
        ├─ chargerUtilisateurs() - Query BD tous utilisateurs
        ├─ afficherEtapeType() - Render étape 1
        ├─ afficherEtapeInfo() - Render étape 2 avec recherche
        ├─ mettreAJourParticipants() - Render badges
        └─ creerDiscussionFinal() - Validation + création

Structure CSS:
  chat-modern.css
    ├─ Variables thème (28 variables)
    ├─ Panneau conversations (360px)
    ├─ Zone chat (flex: 1)
    ├─ Messages et bulles
    ├─ Indicateur saisie
    ├─ Zone saisie avec textarea
    ├─ Responsive breakpoints (1024px, 768px, 480px)
    └─ Support mode sombre (@media prefers-color-scheme)
